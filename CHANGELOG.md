# 📰 AiKit changelog

## 0.1.0

- Initial portable document codec, examples, bounded parsing, and tests.
- Selected live-shape gradient isolation with copied styles and counted resources.
- Relative CC gradient placement editing with synchronized native and printing geometry.
- Source-backed CC mesh inspection with mixed color spaces and intermediate boundary nodes.
- Shared mesh vertex color/opacity editing, typed ink alternatives and global resource scanning fixes.
- Native Separation/NChannel mesh tint editing with PDF-qualified component ordering and unchanged ink declarations.
- Removed development native-to-PDF rendering and mesh interpolation APIs to keep rendering in the host application.
- Retained native editing and serialization with host-supplied PDF appearances; documented the package/host contract and migration.
- Added bounded source-local capability reports with operation-specific qualifications and explicit preservation, unsupported-data and parser-limit diagnostics.
- Added atomic multi-program saving and rejected stale native metadata, foreign graphs and implicit PDF page remapping.
- Added explicit text-layout invalidation for changed host dependencies without rewriting text or resources.
- Added bounded host-supplied CC printing contours while preserving native authoring records, paints, compound groups and shared resources.
- Synchronized CC point-count headers during plain-path and printing-contour replacement, with atomic rejection of ambiguous or stale counts.
- Added complete host-supplied CC printing groups with bounded topology/paint changes, existing gradient references and preserved outgoing state.
- Added source-owned document settings, explicit ruler units/canvas scale and artboard document/order/ruler-origin metadata.
- Added immutable source ownership, ordered record fields, saved artboard/XML identifiers and both version branches, with explicit shared style/gradient reference resolution.
- Retained duplicate known-style definitions for inspection while rejecting dependent edits without unique ownership.
- Added qualified ordinary-path insertion, duplication, removal, sibling reordering and same-layer group moves, preserving inherited state and native point counts.
- Added ordinary group creation, ungrouping, duplication, removal, reordering and same-layer reparenting with source-backed incoming/outgoing paint and object-state preservation.
- Added source-owned layer wrappers, names, identities and nested ownership, with qualified empty sibling insertion, synchronized root counts and explicit saved-view invalidation.
- Added qualified layer subtree reordering and reparenting with retained identities, source-backed paint-state preservation, synchronized root counts and explicit destination inheritance.
- Added atomic ordinary-layer duplication with fresh descendant identities and optional copied names, plus removal with explicit native-reference qualification and retained outgoing state.
- Extended ordinary path reordering and movement across qualified paint-state changes, preserving outgoing state and requiring explicit inheritance for different ancestor-group flags or depth.
